# Домашнее задание №2. Примитивная база данных

Выполнено учеником М26-555 Кистиным Захаром.

Это консольная программа для работы с небольшой базой данных. В ней можно
создавать таблицы, добавлять записи, искать их по условию, менять значения
и удалять данные. Таблицы сохраняются в JSON, поэтому данные остаются после
закрытия программы.

## Установка и запуск

Для запуска нужны Git, uv и Python 3.12 или новее. Если Git ещё не установлен,
его можно скачать с [официального сайта](https://git-scm.com/install/windows).

Установить uv в Windows можно через PowerShell:

~~~powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
~~~

После установки нужно открыть новый терминал. Другие способы установки uv
есть в [инструкции](https://docs.astral.sh/uv/getting-started/installation/).

Затем скачать проект и установить зависимости:

~~~powershell
git clone https://github.com/MarchiYT/project-2_Kistin_M26-555.git
cd project-2_Kistin_M26-555
uv python install 3.12
uv sync --python 3.12
uv run database
~~~

Если проект уже скачан, достаточно перейти в его папку и выполнить
`uv sync --python 3.12`, затем `uv run database`.
Команда `uv run project` запускает ту же программу.
При запуске появится список команд. Дальше команды вводятся по одной после
строки «Введите команду:». Чтобы закончить работу, нужно ввести `exit`.

## Команды

| Команда | Что делает |
| --- | --- |
| `create_table users name:str age:int is_active:bool` | Создаёт таблицу users |
| `list_tables` | Показывает список таблиц |
| `insert into users values ("Sergei", 28, true)` | Добавляет запись |
| `select from users` | Показывает все записи |
| `select from users where age = 28` | Показывает записи по условию |
| `update users set age = 29 where ID = 1` | Меняет значения подходящих записей |
| `delete from users where ID = 1` | Удаляет подходящие записи |
| `info users` | Показывает столбцы и количество записей |
| `drop_table users` | Удаляет таблицу |
| `help` | Повторно выводит список команд |
| `exit` | Завершает работу |

При создании таблицы автоматически добавляется столбец `ID:int`.
При вставке значения ID вводить не нужно. Новый ID равен максимальному ID
в текущей таблице плюс один. В пустой таблице первая запись получает ID 1.
Менять ID через `update` нельзя.

Поддерживаются три типа: `int`, `str` и `bool`. Строки нужно писать
в одинарных или двойных кавычках, числа — без кавычек. Для логических значений
используются `true` и `false` в любом регистре. Например, `"28"` считается
строкой, поэтому в столбец `age:int` такое значение добавить не получится.

Имена таблиц и столбцов могут содержать латинские буквы, цифры и подчёркивание.
Регистр в именах учитывается. Ключевые слова команд пишутся маленькими буквами.

В `where` можно задать одно условие с `=`. Если условие подходит нескольким
записям, обновление или удаление применяется ко всем этим записям.
В `set` разрешено менять несколько столбцов через запятую:

~~~text
update users set age = 29, is_active = false where ID = 1
~~~

Один `insert` добавляет одну запись. Пробелы и запятые внутри строки
сохраняются, например `"Ivanov, Ivan"` — это одно значение.

## Пример работы

~~~text
create_table users name:str age:int is_active:bool
insert into users values ("Sergei", 28, true)
insert into users values ("Ivanov, Ivan", 30, false)
select from users
select from users where age = 28
update users set age = 29 where name = "Sergei"
select from users where ID = 1
info users
delete from users where ID = 2
n
delete from users where ID = 2
y
select from users
drop_table users
y
exit
~~~

Перед `delete` и `drop_table` декоратор `confirm_action` спрашивает
подтверждение. Ответ `y` выполняет удаление. Любой другой ответ, в том числе
пустой, отменяет его.

Если команда написана неправильно, таблицы нет или тип значения не подходит,
программа выводит сообщение об ошибке и ждёт следующую команду.

Декоратор `log_time` показывает время выполнения `insert` и `select`.
Результат повторного `select` для той же таблицы и того же условия берётся
из кэша. После добавления, изменения или удаления данных кэш очищается.

## Где хранятся данные

Структура таблиц записывается в `db_meta.json`, а записи — в
`data/<имя_таблицы>.json`. Эти файлы создаются в папке, из которой запущена
программа. Чтобы открыть ту же базу в следующий раз, нужно запускать
программу из той же папки. При удалении таблицы её файл тоже удаляется.
Локальные данные и виртуальное окружение не добавляются в репозиторий.

Исходный код находится в `src/primitive_db`. В `main.py` — запуск,
в `engine.py` — ввод и выполнение команд, в `core.py` — операции с таблицами
и записями. `parser.py` разбирает команды, `utils.py` читает и сохраняет JSON,
`decorators.py` содержит декораторы и кэш, а `constants.py` — общие значения.

## Проверка и сборка

~~~powershell
uv run ruff check .
uv build
uvx twine check dist/*
~~~

Готовые пакеты появятся в папке `dist`. Для отдельной установки wheel:

~~~powershell
uv tool install --python 3.12 dist/primitive_db-0.1.0-py3-none-any.whl
database
~~~

В Makefile есть команды `make install`, `make run`, `make lint`,
`make build` и `make check`. Для них нужен установленный Make.
Перед `make check` нужно выполнить `make build`.
