# Примитивная база данных

Программа создаёт таблицы, хранит записи в JSON и выполняет команды из консоли.
Для работы нужны Python 3.12 или новее и uv.

## Установка и запуск

~~~powershell
git clone https://github.com/MarchiYT/project-2_Kistin_M26-555.git
cd project-2_Kistin_M26-555
uv sync
uv run database
~~~

Вместо `database` можно использовать `uv run project`.
После запуска введите `help`, чтобы увидеть все команды, или `exit`, чтобы выйти.

Если uv ещё не установлен, инструкция находится на
[сайте uv](https://docs.astral.sh/uv/getting-started/installation/).

## Пример работы

~~~text
create_table users name:str age:int is_active:bool
list_tables
insert into users values ("Sergei", 28, true)
insert into users values ("Ivanov, Ivan", 30, false)
select from users
select from users where age = 28
update users set age = 29 where name = "Sergei"
select from users where ID = 1
info users
delete from users where ID = 2
y
drop_table users
y
exit
~~~

Столбец `ID:int` добавляется автоматически. При вставке ID указывать не нужно.
Новый ID равен максимальному ID среди текущих записей плюс один, а в пустой
таблице начинается с 1. Изменять ID командой `update` нельзя.

Имена таблиц и столбцов чувствительны к регистру. Разрешены латинские буквы,
цифры и знак подчёркивания. Поддерживаются типы `int`, `str` и `bool`.
Строки записываются в одинарных или двойных кавычках. Числа пишутся без
кавычек, логические значения — `true` или `false` в любом регистре.

В `where` используется одно равенство. В `set` можно указать несколько
столбцов через запятую. Каждая команда `insert` добавляет ровно одну запись.
Ключевые слова команд вводятся маленькими буквами.

Перед удалением записи или таблицы программа спрашивает подтверждение.
Ответ `y` разрешает удаление; любой другой ответ отменяет действие.
Ошибочная команда выводит сообщение, после которого можно продолжить работу.

Декоратор `log_time` выводит время выполнения `insert` и `select`.
Повторный `select` с тем же условием берёт результат из кэша и не запускает
поиск заново. После изменения данных кэш очищается.

## Файлы базы

Метаданные сохраняются в `db_meta.json`, записи — в `data/<table_name>.json`.
Файлы создаются в текущем каталоге. Чтобы продолжить работу с прежней базой,
запускайте программу из той же папки. После удаления таблицы её JSON-файл
тоже удаляется. Файлы базы не добавляются в Git.

## Проверка и сборка

~~~powershell
uv run ruff check .
uv build
uvx twine check dist/*
~~~

При установленном Make доступны команды `make install`, `make run`,
`make lint`, `make build` и `make check`.
`make check` проверяет уже собранные пакеты. Для этого сначала выполните
`make build`.

Собранный wheel можно установить отдельно:

~~~powershell
uv tool install --python 3.12 dist/primitive_db-0.1.0-py3-none-any.whl
database
~~~

Публикация пакета в PyPI для запуска проекта не требуется.
